# Portafoglio di Federico

App personale per investimenti, simulazioni con le tasse italiane, mutui e finanziamenti.
Si installa sul telefono e sul PC (PWA) e funziona anche offline.

**Nel repository non ci sono dati.** I dati stanno sui dispositivi e nel Foglio Google privato,
collegato tramite l'app web Apps Script (`apps-script/Code.gs`) protetta da un codice segreto.

File: `index.html`, `app.js`, `sw.js`, `manifest.json`, icone, `apps-script/Code.gs`.
